# Mini-Project: Access Control System via Tones

**Course:** Sensors and Signals (2025-2026)
**Institution:** University of Aveiro, Department of Electronics, Telecommunications and Informatics

## Project Description
This project consists of developing a tone detection system using an ESP32C6 microcontroller and an analog microphone. The ultimate goal is to decode sounds generated, e.g., by a telephone or a PC, and use them as input for a practical application, in this case, simulating an access control system.

The system bridges theoretical concepts (signals, spectrum, filters) and their application in embedded systems and general computing, based on the concept of "in-band signaling" (DTMF type).

## Hardware and Connections
For the system to function correctly, the hardware connections must follow this configuration:
* **Microcontroller:** ESP32C6
* **Analog Microphone:** SPW2430 connected to the `ADC_CHANNEL_3` input.
* **Actuator (Emulated Door):** LED connected to `GPIO11`.

## System Operation
Access control is based on real-time audio processing and symbol pattern detection:
* The system must detect a sequence of 4 symbols ("0", "1", or "2").
* The sequences are chosen by the students and correspond to the "open" and "close" commands of a door.
* The door is emulated by an LED (on=open, off=closed).
* The detection of a wrong sequence is signaled by the LED blinking for 5 seconds.

### Signal Processing
* Detection is performed by applying FIR filters.
* The only specific function from the Espressif-IDF DSP library that can be used is the convolution function (`dsps_conv_f32`).
* The base firmware flow configures the ADC, decodes the frames generated by it, and places the acquired sound samples into a FIFO.
* A task reads the FIFO and is triggered whenever it has new data. The code to be developed by the students should be placed inside this task.

## Frequency Configuration
The frequencies corresponding to each digit must be calculated as follows:
* **Frequency "0":** class number multiplied by 500 Hz.
* **Frequency "1":** frequency of "0" plus 700, plus the sum modulo 10 of the digits that make up the group members' student ID numbers multiplied by 20.
* **Frequency "2":** frequency of "1" plus 700, plus the sum modulo 10 of the digits that make up the group members' student ID numbers multiplied by 20.

**Group Values:**
* Class: `P1`
* NMECs (Student IDs): `120152` and `126323`
* Frequency "0": `500 Hz`
* Frequency "1": `1360 Hz`
* Frequency "2": `2220 Hz`

## Access Sequences
* **OPEN Command:** `1200`
* **CLOSE Command:** `2011`

## How to Compile and Run
1. Extract the project "zip" file. It can be built on any PC with the ESP-IDF toolchain installed.
2. Navigate to the project directory in your terminal.
3. Run `idf.py build` to compile the code.
4. Run `idf.py -p [PORT] flash monitor` to flash the firmware to the ESP32 and open the serial monitor.
