## PWN

With these 4 resources you should be more than fine.

- [PWN college](https://pwn.college/) Practice and learn lots
- [ROP emporium](https://ropemporium.com/) Practice a lot of common scenarios
- [Nightmare](https://guyinatuxedo.github.io/) One of the best "theorical" courses\
- [pwnable.kr](https://pwnable.kr/) pure practice (can be hard at first)


If you like youtube more, [crypto cat](https://www.youtube.com/playlist?list=PLHUKi1UlEgOIc07Rfk2Jgb5fZbxDPec94) is great to start learning pwn.
